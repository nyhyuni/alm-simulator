# ALM Simulator

Python implementations of interest rate models used in asset-liability management (ALM), fixed income, and insurance risk management.

## Current Models

* Brownian Motion with Drift
* Vasicek Mean-Reverting Interest Rate Model

## Tech Stack

* Python
* NumPy
* Pandas
* Matplotlib

## Roadmap

* Model comparison
* Duration and PV01 analytics
* Bond portfolio simulation
* ALM scenario analysis
